First-time tablet setup
  1. Turn on Developer options on the tablet: open Settings › About tablet and tap Build number 7 times. (Amazon Fire: Settings › Device Options › About Fire Tablet, tap Serial Number 7 times.)
  2. In Developer options, turn on USB debugging.
  3. Install adb on this Mac if needed: brew install android-platform-tools.
  4. Connect the tablet with a USB cable and tap Allow on the “Allow USB debugging?” prompt (check “Always allow”).
  5. Amazon Fire tablets are set up automatically. For any other tablet, click Use next to it under Connection in the Tablet section.
  6. Click Install App on Tablet above. The display opens automatically and starts whenever the tablet boots or is plugged in.

No cable? Download the APK in the tablet’s web browser from the Wi-Fi address shown above, install it, then long-press the top-left corner of the display to enter that address.
